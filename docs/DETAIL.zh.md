## 做了什么

- **整窗长绒**：侧栏是裸绒，对话区叠一层半透明浅蓝，绒毛纹理在主色上，所以换毛色不用换图。
- **毛边气泡**：用户气泡与输入框用 SVG 位移滤镜把边缘打毛，只在容器上作用，文字干净。
- **棕色纽扣**：品牌标记、发送键做成玩偶胸前的纽扣。
- **小团子**：输入框右上角趴着一只小 Muse，眨眼、轻微起伏，可在皮肤管理里关掉。
- **夜间**：深蓝灰绒 + 暗米色肚皮，同一只玩偶关了灯。

![Muse 毛绒（夜间）](preview/dark.png)

## 设置

「设置 → 皮肤管理 → Muse 毛绒」：小团子开关、毛边开关、绒长（短/标准/长）、毛色、耳朵与肚皮色。

## 兼容

DSH Web 0.2.2-rc 系列；只在 `body[data-dsh-muse-plush]` 下作用，不 import Harness 客户端包，卸载不残留。
